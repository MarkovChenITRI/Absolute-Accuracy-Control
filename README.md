# Universal-Embodied-SDK

`/tune` 是晶圓機器人有片取放的伺服參數調校 mod，在 Claude Code 中統一調度調機所需的軟體，適用單臂、雙臂及軸數不同的機型（如 WR403、WR503）。調度的軟體如下，對機器人只讀不寫：

* **Claude Code**：`/tune` 的執行環境，在對話中引導使用者完成調機的每一步。
* **PickPlace Tuner**：本專案的應用程式，匯入各軟體的資料、計算振動指標，並管理參數檔與量測資料的版本。
* **MR Configurator2**：三菱 MR-J5 驅動器的設定軟體，Claude Code 透過它讀寫各軸參數，並量測速度與轉矩的圖表波形與頻譜。
* **MS1811**：外部振動感測器的獨立軟體，匯出末端 X/Y/Z 加速度 CSV。
* **RASeMIO**：機器人控制器的唯讀查詢介面，取得取片模式、動作狀態、速度、加減速與關節位置。

Claude Code 會協同使用者完成[標準作業流程](docs/標準作業流程.md)裡寫的流程操作。調機先放片量測負載慣量比 PB06，取樣穩定後把平均值寫入，作為增益計算的基準；接著依下表調整增益參數：

| 參數 | 調整方向 | 限制條件 | 觀測方法 | 寫入設定 |
|---|---|---|---|---|
| 速度控制增益 PB09 | 1.05 逐倍往上 | 不發生振動或異音 | 工程師在機台現場目視、聽覺確認 | 振動發生值 × 0.75 |
| 速度積分補償 PB10 | 1.05 逐倍往下 | 不發生振動或異音，且 PB10 ≥ 2000 ÷ (PB09 ÷ (1 + PB06)) | 工程師在機台現場目視、聽覺確認 | 振動發生值的前一級；降到下限仍不振動時，取下限值 |
| 位置控制增益 PB08 | 1.05 逐倍往上 | 不發生振動或異音 | 工程師在機台現場目視、聽覺確認 | 振動發生值的前一級 |
| 模型控制增益 PB07 | 1.05 逐倍往上 | 定位過衝量 ≤ 到位範圍 PA10 × 過衝容許位準 PA25% | Claude Code 讀 MR Configurator2 | 過衝發生值的前一級 |
| 過衝量補償 PB12 | 直接計算 | — | Claude Code 讀 MR Configurator2 | PB07 降到 PB09 ÷ (1 + PB06) × 1/8 仍過衝時，填 等速時轉矩 × 等速時速度 ÷ 額定速度 |

振動發生值與過衝發生值是第二片的參數值，前一級是第一片的參數值。調增益之前，濾波器與抑制振動控制先全部關閉。增益調完後，在每一段有片動作量頻譜，高於該段平均值 + 3 倍標準差的峰稱為波峰；濾波器看速度與轉矩不匹配處的頻譜，抑制振動控制與指令陷波看滯留脈衝的頻譜。各段都有波峰時，每次只處理其中最高的一個，依下表加濾波器。每加一次濾波器，就回到增益表重調，因為濾波器壓住共振後增益還能再往上加。增益與濾波器這樣來回，直到各段都量不到波峰；濾波器用盡仍壓不住，判定為結構問題、停止調整：

| 參數 | 調整方向 | 限制條件 | 觀測方法 | 寫入設定 |
|---|---|---|---|---|
| 濾波器 1（自適應）PB13、PB14 | 逐級加深、放寬 | 各段都沒有波峰為止 | Claude Code 讀 MR Configurator2 | 陷波頻率取調諧結果 |
| 濾波器 2、5、3、4（手動陷波）PB15–PB16、PB46–PB51 | 逐級加深、放寬 | 各段都沒有波峰為止 | Claude Code 讀 MR Configurator2 | 陷波頻率填最高波峰的頻率 |
| 低通、軸共振抑制、Robust 濾波器 | 不調整 | — | — | 自動、自動、無效 |

增益與濾波器不再來回後，才依下表設定抑制振動控制，因為它依當時的增益推定。頻率超出模型控制增益 PB07 的允許範圍時，降 PB07 一級並重新調諧，降到下限仍不行即判定為結構問題：

| 參數 | 調整方向 | 限制條件 | 觀測方法 | 寫入設定 |
|---|---|---|---|---|
| 抑制振動控制 1、2 PB19、PB20、PB52、PB53 | 對準量到的振動頻率 | 有片停止後滯留脈衝沒有波峰為止 | Claude Code 讀 MR Configurator2 | 先取自動調諧結果；仍有波峰時，振動頻率與共振頻率都填量到的頻率 |

抑制振動控制處理不了的振動，交給指令陷波濾波器：被 PB07 擋住的低頻、超過兩個的頻率，以及運轉中的晃動。它從位置指令削掉該頻率，不受 PB07 限制，也不影響增益與濾波器，改了不必回頭重調；只有一組，給有片時最高的波峰頻率。用盡仍有波峰時降 PB07 一級，並回到抑制振動控制重新調諧：

| 參數 | 調整方向 | 限制條件 | 觀測方法 | 寫入設定 |
|---|---|---|---|---|
| 指令陷波濾波器 PB45 | 逐級加深 | 有片時滯留脈衝沒有波峰為止 | Claude Code 讀 MR Configurator2 | 頻率選最接近振動頻率的設定值 |

```
Universal-Embodied-SDK
 ├ .claude-plugin/     # 外掛目錄清單，供安裝指令找到 mods/ 底下的 mod。
 ├ mods/               # /tune 的外掛設定、程式碼與測試。

```

## 一、配置 `/tune` 與取得 PickPlace Tuner

Claude Code、MR Configurator2 與 MS1811 是既成軟體，依各自的方式安裝。

1. 打開終端機，切到 GitHub 工作路徑，下載本專案並把它登記為 Claude Code 的外掛來源：

   ```bash
   git clone https://github.com/MarkovChenITRI/Universal-Embodied-SDK
   claude update
   claude plugin marketplace add ./Universal-Embodied-SDK
   ```

2. 安裝 `/tune`，裝完後重開 Claude Code 工作階段：

   ```bash
   claude plugin install tune@pickplace-tuner
   ```

3. 到 [Releases](../../releases) 下載 `PickPlace-Tuner.exe` 與設定檔，放在工程機的同一個資料夾。系統需求為 Windows 10 以上 64 位元，不需安裝 Python。首次啟動出現 SmartScreen 警告時，點 **其他資訊 > 仍要執行**（本程式未做程式碼簽章，屬內部使用）。

## 二、PickPlace Tuner 的使用與建置

### 使用

1. **RASeMIO 連線**：以網路線連接工程機與機器人控制器，工程機網卡設為與機器人同網段的固定 IP。在設定檔填入 `host`（預設 192.168.10.11）與 `port`（預設 4000），啟動 PickPlace Tuner 後按 **連線**，每 0.2 秒保存一次機台狀態。

2. **MS1811 匯入量測**：建立機型設定，匯入 MS1811 匯出的外部感測資料 CSV，校正與機台狀態的對時後選取分析區段，存成一筆量測。

3. **MR Configurator2 參數版本**：匯入執行當下 MR Configurator2 匯出的參數檔，存成一個參數版本並對應到該筆量測；可比較任兩個參數版本的差異。

PickPlace Tuner 將三者對齊到同一筆量測後提供以下分析結果。振動指標涵蓋 X/Y/Z 三軸的 RMS、P99、P99.9、最大絕對加速度，以及超過門檻的百分比、事件次數與最長事件時間。頻譜分析列出主要振動頻率與各頻帶能量，診斷則列出每一次超標事件發生時的取片模式、動作狀態與位置。比較兩筆量測時，並列兩者的參數差異與各項指標的變化幅度。

### 從原始碼建置

1. 在專案目錄安裝相依套件：

   ```bash
   cd Universal-Embodied-SDK
   uv sync
   ```

2. 以開發模式執行，確認畫面與 RASeMIO 連線正常。開發模式的資料庫放在專案根目錄：

   ```bash
   uv run python run.py
   ```

3. 打包成單一執行檔，產物是 `dist\PickPlace-Tuner.exe`，執行時資料庫建在執行檔旁邊：

   ```bash
   uv run pyinstaller --noconfirm PickPlace-Tuner.spec
   ```
